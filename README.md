
# ⚡ Neon Tic Tac Toe

A modern, neon-themed 2-player Tic Tac Toe game built with vanilla HTML, CSS, and JavaScript.

## ✨ Features
- 🎮 2-Player local multiplayer
- 🏆 Win & draw detection
- 📊 Persistent scoreboard
- 🔊 Web Audio API sound effects
- 🎊 Confetti win animation
- 🌙 Neon dark mode UI
- 📱 Fully responsive design
- ✏️ Editable player names

## 🚀 Live Demo
[Play Now][([https://sougatadomain.github.io/neon-tic-tac-toe-/](https://neon-tic-tac-toe-ten.vercel.app/))

## 🛠️ Tech Stack
- HTML5 Canvas (confetti)
- CSS3 (animations, grid, variables)
- Vanilla JavaScript (Web Audio API)
- Zero dependencies — one file!

## 📦 Installation
```bash
git clone https://github.com/YOUR-USERNAME/neon-tictactoe
cd neon-tictactoe
open index.html   # or drag into browser
\```
